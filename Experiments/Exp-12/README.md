

CRUD Operations using Spring Boot REST API.

Operations performed:
- Create Employee (POST)
- Get Employee (GET)
- Delete Employee (DELETE)

Tools Used:
- Spring Boot
- Spring Data JPA
- Postman

Sample JSON:

{
  "id": 1,
  "name": "Abhishek Pratap Singh",
  "department": "CSE",
  "salary": 50000
}
